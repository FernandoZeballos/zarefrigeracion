## 🚀 Descripción del Proyecto

Z.A. Refrigeración es una plataforma web "Mobile-First" diseñada no solo como un portfolio de servicios, sino como un **embudo de ventas de alta conversión (Lead Generator)**. Migrada estructuralmente desde Vite hacia **Next.js (App Router)**, prioriza el SEO orgánico, la carga ultra-rápida y la reducción absoluta de fricción para el usuario.

## 🎯 Mejoras de Conversión (CRO) Incluidas

- **Texto Persuasivo (Copywriting):** Titulares orientados a beneficios inmediatos (_"Tu Aire Listo Hoy. Sin Vueltas."_).
- **Formulario "Wizard" Multi-Paso:** Dividido en 3 pasos interactivos sin fricción (Diagnóstico -> Zona -> Contacto) para reducir la carga cognitiva apoyado en navegación por teclado inteligente (`Enter`).
- **Botón Flotante de WhatsApp:** Sticky call-to-action con pulsaciones de diseño y logo oficial para capturar leads móviles con una conversión táctil intuitiva.
- **Modelo Interactivo 3D:** Un aire acondicionado en 3D interactivo desarrollado en `@react-three/fiber` atrae e involucra al usuario durante los primeros segundos críticos.
- **Social Proof Incorporado:** Señales visuales de confianza estratégica ("Más de 500 clientes...", "Maestro Mayor de Obra").

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 15 (App Router) / React 19
- **Estilos:** Tailwind CSS v4 / Variables Dinámicas de Tema
- **Gráficos 3D:** Three.js / @react-three/fiber / Drei
- **Iconografía:** Lucide-React
- **Despliegue Recomendado:** Vercel

## 📦 Instalación Local

Para correr el proyecto en tu entorno de desarrollo:

```bash
# Instalar dependencias
npm install

# Ejecutar el servidor de desarrollo en http://localhost:3000
npm run dev
```
